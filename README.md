## 号称三网优化，怎么分辨真假

香港 VPS 市场上“三网优化”被用得太随便。常见做法是只有移动去回程走 CMI，电信和联通绕道美国或日本，延迟照样能跑到 150ms 以上，宣传页上仍写“三网直连”。分辨这件事，先要知道几个名词各自代表什么。

- **CMI**：中国移动国际，移动用户回国最直接的路径。
- **CN2 GIA**：电信的精品承载网，去回程都走，成本最高，晚高峰最稳。
- **AS9929 / AS4837**：联通的精品线路，9929 更贵更难拿，4837 相对普遍。
- **CMIN2**：移动的精品网，比普通 CMI 优先级更高。
- **AS10099**：联通国际，常和 4837 搭配出现，属于联通系优化。

“三网优化”成立的前提是三家各走各的优质路径。只有移动走 CMI、电信联通从美西绕回来，那叫单线优化。

拿 IP 之后怎么验？三条路，按可靠程度排：

1. **看回程路由**。在机器上对国内三网测试 IP 做 traceroute，看最后一跳进入大陆前经过哪个 AS。电信回程出现 4809（CN2）或 4134 直连，和出现绕美西的节点，是两回事。
2. **看商家敢不敢标“回程”**。只写“三网优化”不写具体线路名的，通常有水分；把去程回程分列、标出 AS 号的，可信度高得多。
3. **晚高峰自己测**。晚上八九点 ping 一遍国内三网节点，延迟比白天涨 3 倍以上的，说明走的是普通公共出口。

Akile 香港这两条线里，HKLite 属于普通线路，官方也没把它包装成精品回国；BGP Plus 的路由记录是公开可查的，电信联通走 AS10099 系、移动走 CMI。这个描述比“三网直连”准确，也比“三网直连”保守。
